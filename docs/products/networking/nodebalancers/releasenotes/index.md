This is the release notes landing page.

The shortcode below will list the release notes with a link to the complete version:

The below is produced by `{{%/* releasenotes/list path="nodebalancers" limit=10 */%}}`.

{{< releasenotes/list path="nodebalancers" limit=10 >}}

## Shortcode parameters

* `path` is the section path to the release notes section below `/docs/releasenotes`.
* `limit` lists the last `n` release notes, default is to list everything.
